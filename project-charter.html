Project Proposal · 立项文档

高校毕业生就业数据统计分析

基于多源公开数据的专业—行业—区域就业结构分析，为应届生专业选择与求职区域决策提供可溯源的数据参考。

项目类型个人独立分析项目 当前阶段立项 / 方案设计 技术链路采集 → 治理 → EDA → 可视化 → 结论 数据性质全部公开、可溯源

01项目背景与业务目标

1.1 业务背景

高校毕业生规模连续多年处于高位，而专业设置与市场需求之间的信息不对称长期存在。应届生在“选什么方向、去哪个城市、进哪个行业”这三个关键决策上，主要依赖经验判断和碎片化信息，缺少可核验的量化参考。

另一方面，教育部、各高校、国家统计局与第三方招聘平台每年产出大量公开就业数据，但这些数据分散在 PDF 报告、网页表格与年鉴 Excel 中：指标口径不一、统计时点不同、年份序列断裂、院校公开率参差不齐。直接把这些数字拼在一起做比较，会得出看似有据、实则错误的结论。

核心业务问题

基于公开就业数据，回答：不同专业大类、行业与区域的毕业生去向落实情况与薪酬水平，呈现怎样的结构性差异？应届生应如何据此调整求职策略？

项目的价值不在于“采集了多少条数据”，而在于把不可比的原始数字，转化成可比的口径统一指标，并据此给出可执行建议。

1.2 明确不做的事（项目边界）

立项阶段先划边界，比后期删需求更省成本：

不做个体薪资预测模型（样本量不支持） 不做高校 / 专业排行榜（维度单一、易被误用） 不采集非公开、需授权或含个人信息的数据

1.3 三层目标（可验收）

层级目标可验收成果
业务层 输出专业—行业—区域三维就业结构画像，识别结构性错配 3–5 条带数据证据的结论 + 可执行建议清单
数据层 整合 ≥4 类异构数据源，建成口径统一的毕业生就业指标宽表 宽表 + 口径映射字典 + 数据质量报告
能力层 完整走通采集→治理→分析→可视化→结论全链路并留下可复现代码 Git 仓库 + 可视化看板 + HTML 分析报告

02项目整体流程架构

采用五阶段流水线，每个阶段定义输入、动作、产出、质量门禁四要素。门禁未通过不进入下一阶段，避免错误数据污染下游结论。

S1

数据采集

动作 网页表格抓取、PDF 报告解析、年鉴 Excel 下载

产出 按数据源分目录落地的原始数据

门禁 每条记录必须带 source_url + fetch_time + 原文页码

S2

清洗与口径治理

动作 字段标准化、口径映射、实体归一、缺失与异常处理

产出 清洗层数据 + 口径映射字典 + 质量报告

门禁 核心字段缺失率达标；口径映射覆盖率 100%，无法映射者标 unknown 并单独计数

S3

EDA 探索分析

动作 分布、分组对比、时间趋势、交叉分析与相关性检验

产出 分析笔记，每条结论附对应图表与数据切片

门禁 结论必须能回溯到具体查询语句，不接受“看图说话”

S4

可视化呈现

动作 静态图表 + 交互看板，统一视觉规范与图注

产出 图集与看板，含图表说明文字

门禁 每张图必须标注口径、样本量与数据截止时间

S5

结论输出

动作 结构化写作：现象 → 证据 → 归因假设 → 建议 → 局限

产出 HTML 分析报告（作品集页面）+ 简历要点

门禁 无数据支撑的判断一律删除或降级为“待验证假设”

2.2 关键治理点：口径对齐（本项目核心难点）

这是整个项目最有技术含量的部分，也是与其他“爬完就画图”的学生项目拉开差距的地方。

问题 A · 就业率口径变更。教育部自 2021 年起以“毕业去向落实率”替代原有“就业率”表述，两者统计范围并不等价；各高校的统计截止时点存在 8月31日 与 12月31日 两种，分母是否包含升学、是否计入灵活就业与自由职业也不一致。

处理。在宽表中新增 metric_definition（指标定义）、cutoff_date（统计截止时点）、includes_further_study（是否含升学）、includes_flexible（是否含灵活就业）四个口径字段。跨口径数据禁止直接比较，仅在四字段完全一致的子集内做横向对比，其余仅做同口径纵向趋势。

问题 B · 青年失业率口径调整。16—24 岁劳动力失业率的统计口径在近年发生过调整（现行口径不含在校生），早期与近期数据不可直接连线。

处理。宏观背景指标做分段标注，趋势图中以断点或不同线型呈现，图注明确写出“口径变更，前后不连续”。

问题 C · 实体名称不统一。同一所高校存在全称、简称、曾用名；专业名称在本科目录与职业教育目录中分属不同层级；行业名称在国家标准分类与各校自拟表述间差异大。

处理。建立三张映射表（高校 / 专业 / 行业），专业按“门类—专业类—专业”三级归一，映射表随清洗过程持续补全，最终作为独立交付物输出。

03数据源说明

数据源按“权威性—颗粒度—可得性”三方面做分层组合：官方统计提供基准与年份序列，高校报告提供最细颗粒度，第三方调研做交叉校验，需求侧数据作为可选补充。

数据源主要内容形态与获取方式在本项目中的用途
A 类 · 官方统计（权威、口径稳定、年度粒度）
教育部《全国教育事业发展统计公报》 毕业生总量、层次结构（研究生/本科/高职）、学科分布 网页 + PDF，公开可得 提供总体基数与年份序列，用于计算各项比例的分母
国家统计局《中国统计年鉴》《中国劳动统计年鉴》 分行业就业人员数、城镇非私营单位分行业平均工资 年鉴在线版 / Excel，公开可得 建立行业薪酬基准线与行业就业容量，与毕业生流向交叉
国家统计局月度城镇调查失业率 全国城镇调查失业率、16—24 岁劳动力失业率 网页数据表，需按口径分段处理 作为宏观景气背景，解释趋势变化的时点背景
B 类 · 高校微观数据（颗粒度最细，质量为项目主战场）
各高校《毕业生就业质量年度报告》 分学院/分专业毕业去向落实率、升学率、行业流向、地域流向、单位性质分布、部分公开薪酬 各校就业信息网 PDF，结构不统一，需解析与抽样 项目主数据源，支撑专业级与院校级分析
抽样策略 — 按“双一流 / 普通本科 / 高职高专”分三档分层抽样，优先选择同一省份或同一行业特色院校 控制样本结构，避免结论被头部高校垄断；高职样本单独成组分析
C 类 · 第三方调研（需求侧与主观感知，用于交叉验证）
智联招聘《大学生就业力调研报告》
麦可思《中国大学生就业报告》		 求职偏好、期望薪资、offer 获取情况、能力自评 公开摘要版 PDF / 新闻稿 与供给侧数据交叉校验，识别“学校口径”与“学生感知”的偏差
D 类 · 需求侧对照（可选，视工期决定是否加入）
公共招聘平台公开岗位信息 按专业关键词抽样的岗位数、技能要求、薪资区间 网页，仅抓公开列表页，遵守 robots 与访问频率 计算“岗位需求 / 毕业生供给”比值，为专业错配提供需求侧证据

3.1 选源原则

① 优先官方、可溯源，拒绝来源不明的二手转述数据；② 单一数据源不单独支撑结论，关键判断至少双源交叉；③ 每个数据源在立项阶段先做可得性小样本验证（下载 3–5 份实测解析成功率），不可行的源及时替换，而不是等到后期才发现解析不了。

说明：上表为数据源清单与用途设计，具体样本院校数量与最终记录条数在数据采集完成后据实填写，不在立项阶段预设结论性数字。

04预期分析问题

五个业务问题按“价值 × 可行性”排序，其中 Q1、Q3 为核心问题（结论最可能站得住），Q2、Q4、Q5 为支撑性问题，工期紧张时优先保证核心问题完成度。

核心

Q1　专业结构性错配：哪些专业“好就业但薪酬低”，哪些“薪酬高但门槛高”？

分析指标
毕业去向落实率、升学率、平均起薪（仅限公开院校）、行业集中度（前三大行业占比）
方法
按专业大类聚合后做分位数分组，构建“落实率 × 起薪”二维散点与四象限划分
产出
四象限图 + 错配专业清单（高落实低薪 / 低落实高薪 / 双高 / 双低）
业务价值
纠正“就业率高＝好专业”的朴素认知，为专业选择提供二维视角
核心

Q3　地域流向与人才留存：毕业生都去哪了，留省率与什么有关？

分析指标
留省就业率、流向 Top5 省份占比、省际流向矩阵、院校所在省份与就业省份的关系
方法
分层对比（按院校层次、按区域）+ 流向桑基图；计算流向集中度指标（HHI）
产出
区域流向桑基图 + 留省率分层对比 + 高流出院校特征描述
业务价值
直接支撑“应届生该去哪个城市”的决策，也可用于观察地方引才政策效果
支撑

Q2　行业流向的三年变迁：哪些行业在扩大吸纳，哪些在收缩？

分析指标
各行业流向占比（分年）、占比变化率、行业集中度
方法
构成比时间序列 + 变化率排序 + 堆叠面积图；与统计年鉴行业就业容量趋势对照
产出
行业流向堆叠面积图 + 上升/下降 Top5 行业清单
注意
行业分类各校自拟程度高，须先经映射表归一，否则趋势会被分类差异污染
支撑

Q4　升学替代效应：升学率上升是否挤压了直接就业？不同层次院校差异如何？

分析指标
升学率、直接就业率、待就业率（分院校层次、分年）
方法
结构变化分析，观察三项占比此消彼长的幅度；按院校层次分组对比
产出
去向结构变迁图 + 层次差异对比
边界
仅描述相关关系，不做因果断言（升学与就业受宏观周期共同影响），此点在报告中明示
支撑

Q5　高职高专与本科的就业结构差异（本人视角的差异化切入点）

分析指标
去向落实率、行业分布、单位性质分布、升学率、起薪（若可得）
方法
分层对比 + 分布形态比较，重点看行业与单位性质的分布差异而非单一均值
产出
层次对比条形图 + 高职就业路径特征描述
差异化
同类学生项目极少单独分析高职样本，“高职院校公开率低”本身就是值得写进结论的数据发现，既是分析结论也是项目局限

05项目局限性说明

局限性不是免责声明，而是结论的适用边界。以下七条将原样写入报告的“局限与声明”章节，并在涉及相应结论处做行内标注。

  1. 薪酬数据缺失严重（最关键的局限）多数高校就业质量报告不公开分专业薪酬，公开者多为区间值或均值，且未说明样本量与统计方法。影响：薪酬维度只能做相对比较与趋势描述，不能输出任何绝对值结论，也无法做分位数分析。
  2. 就业率口径不统一，跨校跨年比较存在系统性偏差统计截止时点（8 月 31 日 / 12 月 31 日）、分母定义、是否含升学与灵活就业均不一致。影响：已通过口径字段隔离处理，但只能保证“同口径内可比”，无法完全还原真实差异。
  3. 数据自报，存在乐观偏差报告由高校自行编制，存在美化动机，去向落实率有高估可能。影响：绝对水平只能作参考，结论重心放在“相对排序与结构变化”上；可交叉校验的部分用第三方数据验证，无法校验处明确标注。
  4. 样本选择偏差：公开报告的高校并非随机样本双一流与公办本科的公开率显著高于民办院校与高职高专。影响：样本对“头部高校”存在系统性倾斜，全样本均值不能代表全国毕业生整体；处理方式是按层次分层并单独报告高职结论，同时把“公开率差异”本身作为数据发现输出。
  5. 以横截面数据为主，缺乏个体追踪数据粒度止于“院校—专业—年份”聚合层，没有个体层面的追踪记录。影响：无法回答“某专业毕业三年后的薪酬增长”这类纵向问题，也不支持因果推断（如“读研是否提升收入”）。
  6. 灵活就业与自由职业的认定模糊该类别内部异质性极大（自媒体、零工、挂靠等），被统一计入“落实”会抬高整体落实率。影响：涉及该类别时单独列出占比并加注说明，不与其他去向合并解读。
  7. 数据时效与可得性风险部分高校逐年下线历史报告，或改为图片型 PDF 需 OCR，采集成本不可控。影响：设定最小可行样本量，无法获取的院校记录为“缺失”而非直接删除，缺失情况在质量报告中统计呈现。
一句话总结局限

本项目能回答的是“公开数据所反映的结构性差异与变化趋势”，不能回答“某个具体专业、具体学校的真实薪酬水平”。所有结论均限定在公开样本范围内，不外推至全国全量。

7.2 作品集版（分段式）

项目背景 高校毕业生规模持续高位，而公开就业数据分散于官方公报、高校报告与年鉴中，口径不一、格式各异，导致应届生难以据此做出可靠判断。

我的工作 ① 数据采集：用 Python 抓取统计年鉴网页表格，用 pdfplumber 批量解析高校就业质量报告，以「来源 URL + 抓取时间 + 页码」三元组保证可溯源。
② 数据治理：发现各校“就业率”存在统计截止时点与分母定义两类不一致，建立 metric_definition / cutoff_date / includes_further_study / includes_flexible 四个口径字段进行隔离，禁止跨口径比较；另建高校、专业、行业三张映射表完成实体归一。
③ 分析呈现：围绕专业错配、区域流向、行业变迁、升学替代、层次差异五个问题完成 EDA，输出四象限图、桑基图与结构变迁图。

关键结论 结项后填写，每条结论必须附数据证据

局限声明 薪酬数据公开度低、就业率口径不统一、样本偏向公开率高的头部高校，结论仅适用于公开样本范围，不外推全国全量。

7.3 面试可能被追问的三个问题（提前准备）

面试官可能问应答要点
“各校就业率口径都不一样，你的分析凭什么可信？” 说明四个口径字段的设计与隔离规则，强调只在同口径子集内比较，且结论重心放在相对排序而非绝对值
“公开报告有美化成分，你怎么处理？” 用第三方调研与统计年鉴交叉校验；无法校验处标注；结论避免使用绝对水平
“样本偏向好学校，结论有意义吗？” 承认偏差，说明分层抽样与高职单独成组的处理，并把“公开率差异”本身作为发现输出
本文档为项目立项阶段的方案设计，所列数据源、分析方法与局限均需在实施过程中按实际情况修订。
所有分析结论仅基于公开可得数据，不涉及任何个人隐私信息；采集行为遵守目标网站 robots 协议与访问频率限制。
