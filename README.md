# 大数据招聘岗位数据分析

> 一个面向求职的完整数据分析项目：**采集 → 清洗 → EDA → 可视化 → 业务结论**
> 作者：谭茹方（四川财经职业学院 · 大数据技术专业 · 2027 届专科毕业生）

用 100 条可溯源的招聘岗位数据，回答三个应届生最真实的困惑：**大数据岗位有哪些分工？专科可报吗、给多少钱？企业要什么技能？**

## 核心结论速览

| 问题          | 数据答案                                                 |
| ----------- | ---------------------------------------------------- |
| 专科能进大数据行业吗？ | 大专可报岗仅 8%，且**面向应届的大专岗为 0**——先就业攒经验再切入                |
| 经验值多少钱？     | 应届 6.5k → 1-3 年 13.25k（**+104%**）→ 3-5 年 20k         |
| 学什么技能最值？    | SQL/Python 打底，**Hadoop/Spark 是词频 Top10 仅有的具体大数据技术栈** |
| 投哪个方向？      | 数据开发/工程（供给 45%）；**避开算法岗（大专可报 0%）**                   |

## 技术栈与亮点

- **合规优先**：商业招聘平台用户协议禁止爬取，故选用零风险开源数据集；同步编写了带 robots.txt 检查、随机限速、退避重试的合规采集框架，可直接替换数据源。
- **工程化**：多源合并 + 城市配额限流 + 维表关联补全 + 落盘断言门禁（source_url 缺失/重复必须为 0）。
- **分析自觉**：右偏分布用中位数；结构性缺失只标注不填补；异常值双规则（IQR+业务上界）核验后"检查但不动手"；单维结论用交叉表复核。

## 局限性

结论用于岗位结构理解与方法论演示；城市维度存在数据源结构偏差，不作为结论。详见报告第 6 节。
